# AI 数据治理平台 · 用户操作手册（单机 POC）

> **文档版本**：v1.0（2026-09-20）
> **读者**：业务与治理用户（数据治理专员、业务分析师、审计/合规查看者）
> **适用环境**：**POC 单机形态**（1 台服务器 + SSH 隧道访问）。**不适用于生产**（生产为 M-Prod 三节点，另行发布）。
> **前置提醒**：本环境是设计方案 4.1.3 的**最小测试环境**——**只做功能联调**，**问答准确率不得在此环境判读**；**不要粘贴真实业务数据**（本环境未做在线 PII 脱敏）。

---

## 1. 怎么进系统（30 秒）

平台**没有对外 443**、也没有 VPN 入口，统一走 **SSH 隧道**：

```powershell
# 在你自己的电脑上（已配置好密钥）
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.ai-datathink\open-tunnel.ps1"
```

脚本会开好隧道并逐个自检（正常输出 `9/9 个入口可用`）。收工关闭：

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.ai-datathink\open-tunnel.ps1" -Stop
```

> 只想看隧道状态、不重开：加 `-Check`。

## 3. 治理门户怎么用（五个页面）

左侧导航即信息架构，顺序固定：

### 3.1 首页 / 能力入口
- 2 个**站内模块**：`智能问答（场景 D）`、`系统状态（运维视角）`（标题右侧有状态徽标：`可用` / `全部正常`）
- 5 个**外部界面**：OpenMetadata、Superset、Airflow、Prometheus、Alertmanager（标题右侧有 `需隧道` 徽标；点击**新窗口**打开）

### 3.2 智能问答（场景 D）
1. 在输入框提问 → 点「提问」
2. 回答下方固定附三样东西，**请一起看**：
   - **LangGraph 节点轨迹**：`retrieve → generate → verify`（说明经过了检索/生成/引用校验三步）
   - **检索到的资产**：本次回答依据了哪些资产
   - **上下文预算**：`估算 x/1800 tokens（实测 y）· num_ctx=4096`（说明"喂进去多少资料"）

**可以这样问（示例）**：
- 「平台里有哪些数据资产？属于哪个服务？」
- 「表 sales.orders_vip 的负责人是谁？」→ 期望回答 **「元数据中未找到」**（**不编造**，这是设计行为）
- 「哪些资产含 PII 标签？」

**行为边界（请知悉）**：
- 回答**只依据元数据上下文**；上下文没有的必须回答「元数据中未找到」
- 引用的资产名若不存在，回答会被标注 **「引用未核实」**（程序化校验，不静默丢弃）
- **同一问题连问两次会明显更快**（模型复用 prompt cache）——**这不代表能力变化**，做评测时必须以"首次提问"为准

### 3.3 治理指标
- KPI：已登记资产总数 / 治理完备度 / 资产覆盖率 / 指标层最近成功 ETL
- 「按实体类型明细」表 + 「指标 ETL 运行记录」表（失败行可展开看 `error` 原文）
- 口径：**只读指标层 `gov_metrics`**（ADR-A6）；**资产覆盖率在接入业务源前为 NULL**，不得用"完备度"替代
- 「数据截至」= 最近一次成功 ETL 时间，指标**每小时更新**（最长延迟 1h）

### 3.4 访问审计与审批（场景 E）
- 本页**只解释能力边界，不提供在线审批表单**：POC 期口径是"**只做事后审计 + 主动告警，不做事前拦截**"（ADR-A3）
- 审批记录如需查看，走 API：`GET /api/v1/approvals`（见《测试入口与用例》）

### 3.5 系统状态（运维视角）
- `Governance Agent 已就绪（version 0.1.0 · scope S3-6 首版）` + 「探测详情」可展开看**原始 `/health` 返回**
- 未就绪时本页给出**降级影响说明**（问答不可用、其余不受影响、替代路径）
- 下方「依赖服务清单」= 服务名 / 访问地址 / 连接类型（**要地址就看这里**）

## 4. 用 OpenMetadata 查资产与血缘

1. 浏览器打开 http://127.0.0.1:8585 并登录
2. **搜索**：顶部搜索框输入表名/服务名
3. **资产详情**：进入实体后可看字段、负责人、标签、**Lineage（血缘）**页签
4. 现状说明：**当前只有 1 个资产**（`airflow_poc.airflow_metadata_poc`，是平台自身的采集 pipeline）；**业务源接入后才会变多**
5. 首页上那些非 0 数字（用户 17 / 角色 17 / 策略 18 / 机器人账号 16 等）是 **OpenMetadata 初始化自带的系统账号与策略**，**不是业务数据**

> 血缘粒度：**作业图级**（作业启动/变更时上报），由 Governance Agent 自研上报（ADR-A7）；对账每天 04:10 跑一次。

## 5. 用 Superset 看指标

1. 浏览器打开 http://127.0.0.1:8088 并登录
2. 现有 1 个看板；数据集来自 **`gov_metrics`**（门户/看板**只读**指标层，**不直连 OpenMetadata 内表**）
3. 注意：指标层每小时刷新，看板**不代表实时**

## 6. 常见问题（FAQ）

| 现象 | 原因 / 处理 |
|---|---|
| 门户打不开 / 所有入口都不通 | 隧道没开或断了 → 先跑 `open-tunnel.ps1 -Check`，不通就重新开 |
| 门户页面还是旧样子 | 浏览器缓存 → **Ctrl+F5 强制刷新** |
| 门户显示"Governance Agent 未就绪" | 属**设计的降级行为**（fail-safe）：问答暂时不可用，其余入口照常；可看「系统状态」页的探测详情 |
| 问答回"元数据中未找到" | **正常**：上下文里确实没有该信息（防幻觉设计），不代表系统故障 |
| 同一个问题第二次快很多 | 模型复用 prompt cache，**不是**能力变化；评测看首次 |
| 看不到"审批台"按钮 | POC 期不提供在线审批放行（ADR-A3），本页只有说明 |
| 忘了某个入口的口令 | 口令在服务器 `.env` 里（见 §7），**不要**在聊天/文档里传 |
| 想自己查告警 | Prometheus（规则与状态）/ Alertmanager（当前告警与静默）；每日 08:30 另有一份**告警日报**落在服务器 `reports/` |

## 7. 账号与口令（不写入文档，按需自取）

- 门户**免登录**；其余入口的账号见 §2 表格
- **口令统一存放在服务器 `/data/ai-governance/.env`**（例如 `OPENMETADATA_ADMIN_PASSWORD` / `SUPERSET_ADMIN_PASSWORD` / `AIRFLOW_ADMIN_PASSWORD`）
- 自取命令（在本机执行，输出只在终端显示）：

```powershell
python "$env:USERPROFILE\.ai-datathink\ssh_exec.py" -- `
  "grep -E '^(OPENMETADATA_ADMIN_PASSWORD|SUPERSET_ADMIN_(USER|PASSWORD)|AIRFLOW_ADMIN_(USER|PASSWORD))=' /data/ai-governance/.env"
```

> 安全口径：口令属**敏感信息**，不得粘贴进文档、工单、聊天或截图；POC 收尾或对外演示前建议**轮换一次**。

## 8. 你能做什么 / 不能做什么（一次性说清）

| 你可以 | 你不可以（POC 边界） |
|---|---|
| 提问元数据问题、看引用与预算口径 | ❌ 期待系统"拦住"某次查询（**只做事后审计**） |
| 看资产、字段、作业图级血缘 | ❌ 期待字段级/事件级血缘（当前为**作业图级**） |
| 看治理指标与 ETL 运行记录 | ❌ 拿本环境的**准确率/性能**做准出判读（4.1.3 明文：本环境只做功能联调） |
| 在 Alertmanager 建**静默** | ❌ 粘真实业务数据（**未做在线脱敏**） |
| 通过 API 发起审批记录（只记录不拦截） | ❌ 把 POC 环境当生产用（生产走 M-Prod 三节点） |
