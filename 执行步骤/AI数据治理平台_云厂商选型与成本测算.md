# AI 数据治理平台 · 云厂商选型与成本测算（POC 单机档）

> **定位**：回答"阿里云还是腾讯云、怎么选、怎么买、多少钱"。
> **输入规格**：《POC 服务器采购需求》3.2 —— 1 台 **24 vCPU / 96GB / 2TB 高 IOPS 数据盘**，包月，POC 周期约 11~14 周。
> **价格来源**：阿里云 / 腾讯云官方价格页（2026-09 抓取，见文末）。**所有金额为目录价量级，下单前必须以官网当日计算器 + 商务报价复核。**

---

## 0. 一句话结论

**选型的第一决定因素不是"哪家更强"——两家在 24C/96G 这个档位能力等价；而是"源业务库 / 企业 Kafka / SSO 落在哪家云"。**

同云 = CDC 不出内网、零跨云延迟、零出云流量费、专线可省。
**决策顺序：同云优先 → 同商务关系 → 同团队熟悉度 → 三者都不占才比参数（此时默认阿里云）。**

---

## 1. 决策优先级（照着走，不要跳）

| 顺序 | 判据 | 结论 |
|---|---|---|
| ① | 源业务库 / 企业 Kafka / SSO 已在某家云 | **直接选那家**（最强理由，压倒后面所有参数） |
| ② | 企业已有某家的框架合同 / 代金券 / 发票与合规流程 | 选那家（省采购摩擦 + 拿折扣） |
| ③ | 平台/运维团队更熟哪家的控制台与 CLI | 选那家（POC 期少踩坑比省几百块重要） |
| ④ | 以上全中性 | 按第 3 节矩阵比参数 → **默认阿里云**（生态最全、目录价最好查） |

> ⚠️ 常见错误：一上来就比"哪家性价比高"。①没确认前比参数毫无意义——跨云跑 CDC 的网络代价远大于标价差。

> 📌 前 3 行是"决定性但取决于内部事实"的维度，其余维度两家都在"够用"线以上。**先花 30 分钟盘前 3 行，再决定要不要看矩阵。**

## 4. 阿里云 / 腾讯云 各自"适合 / 不适合"

| 厂商 | 适合（命中其一即选它） | 不适合 |
|---|---|---|
| **阿里云** | 企业已在阿里云（国内最常见）；要与阿里云 RDS/OSS/消息队列/ACK 打通；后续要上 GPU/AI；要最全文档与镜像源；团队基数大、招人与排障资料多 | 源库/Kafka 在腾讯云（跨云）；企业只有腾讯云商务合同 |
| **腾讯云** | 源库/Kafka/微信生态在腾讯云；已有腾讯云合同或代金券；团队熟腾讯云；预算敏感（蜂驰型等促销力度大） | 源库在阿里云；重度依赖阿里云独有产品（如 MaxCompute） |

> 第三选项：**华为云**——若企业有国产化/信创要求，或已有华为云资源，逻辑同上（同云优先），本文不展开。

## 5. 选购 8 步（含默认值，照着填）

| 步 | 动作 | 默认值 / 建议 |
|---|---|---|
| 1 | **定地域 Region** | 紧邻源库/Kafka/SSO；**不要为省钱选远地域**（跨地域延迟与流量费远超差价） |
| 2 | **定网络** | 与源库/Kafka/SSO **同 VPC 或已打通**（云联网/专线）；CDC 必须走内网 |
| 3 | **选实例族** | 通用型：阿里云 `g9i` / 腾讯云 `S5·SA5`；24 vCPU / 96 GB |
| 4 | **选系统盘** | ESSD PL1 480 GB（仅 OS + Docker） |
| 5 | **选数据盘** | ESSD PL1 或 PL2 2 TB —— **档位由 IOPS 需求定，见 6.4 杠杆 1** |
| 6 | **定计费方式** | **先按量验证 1~2 周 → 转包月 × 3~4 个月**；POC **不要包年** |
| 7 | **配安全组** | 只放行 源库/Kafka/SSO 内网端口 + 跳板机；**不开公网 22** |
| 8 | **开快照 + 监控** | 每日自动快照 + 云监控告警（快照按量，POC 量小） |

## 6. 成本测算

### 6.1 成本构成公式

```
单机总成本 ≈ 实例(CPU+内存) + 系统盘 + 数据盘 + 快照 + 带宽(建议 0) + 可选专线
             其中：实例 = 规格目录价 × 月数 × 时长折扣
                   数据盘 = 单价(¥/GB/月) × 容量 × 月数   ← 最大成本变量
```

### 6.2 阿里云工作示例（华北2·北京，Linux，官方目录价，2026-09）

| 项 | 规格 | 官方单价 | 月成本 | 4 个月合计 |
|---|---|---|---|---|
| 计算 | `ecs.g9i.6xlarge`（24 vCPU / 96 GiB） | **包月 ¥2,863.22/月**（按量 ¥5.9651/时） | ¥2,863 | ¥11,453 |
| 系统盘 | ESSD PL1 480 GB | ≈¥1.0/GB/月 | ¥480 | ¥1,920 |
| 数据盘 | ESSD PL1 2,000 GB | ≈¥1.0/GB/月 | ¥2,000 | ¥8,000 |
| 快照 + 杂项 | 按量 | — | ≈¥200 | ¥800 |
| **合计（数据盘 PL1）** | | | **≈¥5,543/月** | **≈¥22,173** |
| *数据盘升 PL2* | ESSD PL2 2,000 GB | ≈¥2.0/GB/月 | +¥2,000 | +¥8,000 |
| **合计（数据盘 PL2）** | | | **≈¥7,543/月** | **≈¥30,173** |

> 参考：`g9i.6xlarge` 年付月价 ¥2,004.26（≈7 折），但 **POC 只跑 3~4 个月，包年不划算**。
> ESSD 价格随可用区（单/双可用区）与地域变动；ECS 云盘实际单价以官网为准。

### 6.3 腾讯云怎么算（官方计价口径）

腾讯云按 **元/核/月 + 元/GiB/月** 分项计价，标准区另有**时长折扣**：

| 机型（官方金融专区页） | CPU | 内存 | 24C/96G 目录价 | 备注 |
|---|---|---|---|---|
| 标准型 S5 | ¥73.6/核/月 | ¥36.8/GiB/月 | ≈**¥5,299/月** | 金融专区价，**等同上限参考** |
| 标准型 SH2F（海光） | ¥60.8/核/月 | ¥30.4/GiB/月 | ≈**¥4,378/月** | 国产化替代更省 |

- 云硬盘：SSD ≈¥1.76/GB/月；增强型 SSD ≈¥2.19/GB/月（多节点表口径）
- **时长折扣**（标准区 广州/北京/上海/南京）：3-5 个月 **78 折**、6-11 个月 73 折、1 年 64 折

→ **腾讯云标准区实际到手价与阿里云同量级。** 用官网计算器按同一规格各拉一次横向比即可。
→ ⚠️ 金融专区价高于标准区，**不要把金融专区报价当标准区报价**。

### 6.4 三个省钱杠杆（按影响从大到小）

1. **数据盘档位（最大变量）**：2 TB 从 PL1 → PL2，每月多约 ¥2,000。POC 日增 <10 GB、17 个容器，ESSD PL1（约 5 万 IOPS 上限）通常够用 —— **先按 PL1 起，实测 IOPS 打满再在线升档**。
2. **实例时长折扣**：两家年付折扣都很大（阿里云 ≈7 折、腾讯云 1 年 64 折），但 **POC 只跑 3~4 个月，包年会锁死资金**。最优 = 按量验证 → 包月 3~4 个月。
3. **不买公网带宽**：走内网 + 跳板机，公网带宽/流量费直接归零；POC 期无需公网暴露。

## 7. 切换触发条件（什么时候改主意）

| 触发 | 动作 |
|---|---|
| 盘点发现源库/Kafka/SSO 实际在另一家云 | **立即切到那家**（① 压倒一切） |
| 目标地域无对应规格 / 缺货 | 换可用区，或换另一家 |
| 两家同规格 4 个月总价差 >30% 且网络条件都满足 | 选便宜那家 |
| M0 实测 Ollama CPU 推理不达标 → 要上 GPU | 重新比 GPU 供给与价格（阿里云供给稳、腾讯云促销狠） |

---

## 8. 与采购路径 A（闲置复用）的关系

**云不是默认首选。** 先按《POC 服务器采购需求》3.3 清单筛一遍企业闲置机——满足规格则 **¥0 且无出云顾虑**，直接走路径 A。
云端唯一不可替代的价值：**分钟级到位、POC 失败可释放、无硬件残值风险**。所以定位是"过渡与兜底"，不是"先买云再说"。
